## 本阶段变更

- A 的 connected 后诊断同时消费原 helper 生命周期：子端原 failure.code 立即停止，禁止只轮询根授权直到父端超时。额外帧及不合法错误码拒绝；没有新增 wire 批准字段。
- A 子端私有诊断仅写 phase、error_type、failure_code；不保存路径、proof、code、私钥或正文，不参与权限判断。父端最多读取 1KiB，额外字段和非法内容拒绝。写入失败、取消竞争不覆盖原拒绝或取消，线程排空后返回。
- D 可信新实例的普通默认60秒／明确根实例最多120秒接口已消费。所有期限仍受当前双方登记、原 Ticket 和原连接较早期限约束，没有给旧授权加时。
- D 在自身目录窗口初始化时请求显示、置顶及前台；系统不给焦点时提醒。只能作用于原 worker 自有窗口，失败停止，不选择目录、不输入路径、不点击确认。后续只读确认仍默认取消。
