# P1-01：有来源的任务理解协议

日期：2026-10-07。状态：**协议实现及回归通过；整轮仍为in_progress，真实模型语义验收待D06**。

本轮形成可供并行组件开发的代码基线。全量73项检查通过，无失败、无跳过；其中13项验证Intent边界。模型响应由测试控制，数据库、事务、ModelRuntime调用、账本和API处理实际运行。未调用外部LLM，未执行Agent或Runner任务。

Intent通过ModelRuntime.generate调用用户固定模型。这部分任务理解入口不构成未来Agent任务流水线。

## 关键链路

1. Run受理并保存原文、任务、模型绑定和RunInputState。
2. 可信调用边界读取完整来源和当前版本；材料摄取未接入时明确报告不可用。
3. 保存understanding专用ContextSnapshot及绑定，ModelRuntime执行固定模型的结构输出调用。
4. 校验提案schema与Unicode码点逐字位置；保留摘要、假设和缺口。逐字来源正确不证明摘要语义正确。
5. 再次核对权限、取消、Run期限、输入版本和CAS；在同一事务保存理解与可见事件。
6. 新要求使旧指针失效，旧frame仍可作为不可变历史。revise使用完整原文及最新补充，不能只看补充就丢掉原始要求。

同attempt与相同参数重放不会重复模型调用；参数不同返回冲突。新attempt的相同理解可以复用frame版本和事件，但其真实模型消耗仍计入账本。

## 已有Run兼容

P1之前没有RunInputState的Run仍可读取历史和状态。理解/追加要求明确返回`intent_input_set_unavailable`，提示提交新turn；不猜测补充历史、不静默创建来源集合、不删除旧数据。本轮无新数据库表或迁移，迁移头仍是`0003_attempt_identity`。
