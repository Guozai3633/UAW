## A14修复策略

在已经明确配置的`json_object`兼容模式中，先按原严格解析器解析；失败后仅将字符串内部的LF/CR/TAB转换为对应JSON转义，再按原严格解析器及完整schema检查。字符串内容逐字保持；不会补引号/括号、去重复键、猜动作、包裹Markdown或补齐截断。
