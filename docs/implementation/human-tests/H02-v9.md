## 建议先做这三件事

### 1. 保存一份不确定的审阅草稿

1. 点击“质量审阅与反馈”，选择“办公：核对金额与折扣”。
2. 阅读原问题，展开原材料、核对要点、引用和版本；查看完整回答。
3. 能判断的项目自行填写，不确定保持空白；可以只写意见。
4. 点击“保存审阅草稿”，等待明确成功提示。
5. 关闭、重新打开同一样本，核对意见与审阅版本；保存后也可刷新再重开。

所有评分初始为空，模型核验结论仅供查阅。正式提交需要明确题目标准、是否有关键错误、已亲自核对依据及意见，并勾选本人声明。回答质量选“可接受”时还需明确没有关键错误、没有虚构依据。不能确认时继续保存草稿。

正式提交后冻结，下载 JSON 内含原评测器四个文件的字符串与绑定审计；不会改变原回答或费用，也不会接受原成果、结束原任务。

### 2. 对原任务保存一条体验反馈

1. 选择你实际体验过的会话，打开同一面板的“当前任务反馈”。
2. 选择问题类别，写明刚才操作、实际结果和你期望的行为。
3. 保存后关闭重开，点击该条反馈查看；需要时可更新意见。

反馈与事实评分分别保存。反馈无需重新发送任务，也不会重跑模型。没有当前任务时，面板会提示先打开任务。

### 3. 自己体验澄清与纠正

可在新会话先发送“请把这段原文翻译成英文”，未提供原文时观察是否提出具体问题；在原任务补充区给出练习原文，再核对是否接续同一任务。是否提问仍由模型按语义决定。

正式成果可用虚构练习：“写一份5月甲项目的正式 Markdown 简报，共5条，人民币金额，结尾单列风险段，不出现公司名。材料：支出2500元，原型完成，交付时间未知。不得补造项目事实。”然后在原任务补充区改为乙项目并给出新材料，检查其他要求是否保留、旧稿是否可读。

请只对你自己的新练习任务进行取消或接受。旧失败任务保持失败，旧报告只读；不能通过刷新把它恢复成成功。

## 网络、冲突与等待

- 保存结果不确定时，先点“重新读取此审阅”核对；客户端不会自动重发写入。
- 多页面改同一草稿会按版本拒绝过期提交；重新读取会替换尚未保存的本地修改。
- 合法等待澄清或审阅暂停主动执行计时；原调用期限、授权有效期和总费用限制独立保留，接续仍会复查。
- 普通输入框负责新请求，原任务补充区负责当前任务的回答或纠正。
- 退出会清理本地草稿；需要保留的意见请先保存到服务端。
