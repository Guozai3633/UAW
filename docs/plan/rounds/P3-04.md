## 1. 本轮目标

运行多个独立分工并控制父子深度、预算和取消。

## 3. 每项开发任务

1. 支持多个有界子实例同时执行，专业/权限/模型和上下文分别绑定。
2. 限制树深、实例数及总预算，默认不开放无限递归。
3. 让Board/Join核对各子结果版本，子失败可修订计划或如实交付partial。
4. 树级取消停止新节点并对在途效果对账，父只在汇总核验后完成。

## 6. 验收条件与必要验证

- [ ] 两个独立子任务可同时运行，紧耦合工作仍可由单Agent完成。
- [ ] 祖先取消、越深度/预算和角色撤销不会被子节点绕过。
- [ ] 子完成、子失败与总任务成功区分清楚。

状态/版本/权限规则可用受控fixture验证；凡本轮声称真实模型、工具、文件、进程、联网或环境已经可用，必须保留实际回执。Mock、接口示例和HTML演示不能替代真实连通或阶段场景验收。

语义质量按原始需求、材料和证据审阅，不以字数/固定关键词替代；工具退出0也不自动证明整个用户任务完成。只加与本轮风险有关的检查，不追求测试数量。
