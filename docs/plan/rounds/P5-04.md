## 3. 每项开发任务

1. 实现Agent ControlLease显式移交，原控制者丢失栅栏后不能继续提交。
2. 实现TriggerSpec、时区/occurrence_key、queue/skip/parallel和原权限内预算。
3. 触发新Run与节点Scheduler分开，后台通知按明确用户授权和有意义变化处理。
4. dev fixture可启用验收，产品handoff/automations默认关闭；D09决定后续启用范围。
