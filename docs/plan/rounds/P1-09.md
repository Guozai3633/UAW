## 3. 每项开发任务

1. 完成manual批准/拒绝/到期流程，参数Hash/目标版本与批准范围固定。
2. 接LangGraph interrupt/继续的当前审批复核，验证工具调用、批准等待和丢回执重入去重三个案例；完整重启恢复留给P5。
3. 单循环安全边界接收steer与取消，旧目标结果不贡献新目标。
4. 取消传播到正在执行工具/进程，已发生效果和费用保留并对账。
5. 记录可见等待/控制Item；辅助/自动模式仍关闭，复杂图修订留给P3。
