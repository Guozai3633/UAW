[查看全部待定项与最晚决策轮](../DECISIONS.md)

## 3. 每项开发任务

1. 按D10明确请求渠道或社媒产品的范围，仅规划入口/身份/成果反馈适配。
2. 列出能力开关、平台账号授权及外部发布审批映射，不改变核心Agent循环。
3. 把代码/本地访问等不适用能力在产品配置关闭，仍保留UAW核心实现。
4. 后续业务需求确认后另拆实现轮；本轮不承诺内容日历、自动发布或运营策略已实现。
