## 3. 每项开发任务

1. 实现管理员批准的Python/Go环境模板，预装优先，按需安装受来源/网络/权限限制。
2. 环境状态以实际版本和检查回执为准，失败保留日志，不假ready。
3. 管理后台进程、初始化失败、租约、资源回收和成果保留，禁止清理项目根。
4. 如D09选择云执行，再接一个真实CloudBackend并报告实际隔离能力；未选则保持关闭。

- [ ] 实际执行Python检查与go test样例，缺依赖/安装拒绝/初始化失败正确报告。

语义质量按原始需求、材料和证据审阅，不以字数/固定关键词替代；工具退出0也不自动证明整个用户任务完成。只加与本轮风险有关的检查，不追求测试数量。
