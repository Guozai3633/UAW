## 3. 每项开发任务

1. 汇合逐包接受后的准确源码/dist/模型配置，跑受影响整链和独立事实评测；保留原失败和费用。
2. 准备固定体验版本与隔离服务/数据，实际启动和登录预跑；旧H01历史/取消状态不重写，旧快照不热改。
3. 用户本人体验正常提问→回答澄清→补充纠正→粘贴材料成果，含刷新/取消/拒绝与合同需要的接受。
4. 反馈交原owner修复，复体验；本机材料链及协作设施另行验收，不等待它们再开启文本体验。
