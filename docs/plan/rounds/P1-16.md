## 3. 每项开发任务

1. H02-v7固定服务用于本人测试；办公/学术真实诊断、历史保留、工程回归分别记录。本人反馈、成果接受和独立事实质量仍pending，本轮由A完成必要修改，BCD不自动扩包。
2. 复用现有文本/Markdown Artifact与Completion接线，原粘贴材料进入低信任Context，固定用户模型生成成果与准确引用。
3. 按原文契约逐项核验实际成果/证据/版本和未决效果；语义评审按需要，事实质量由P1-15独立发布门槛校准。
4. B接成果阅读、引用定位、补充修改和合同要求的本人接受；普通消息不出现成果接受步骤。
5. 各跑办公和学术真实单Agent样例，缺证据/测试不写passed，保留全部模型失败和费用。

## 6. 验收条件与必要验证

- [ ] 两种样例有原材料、可读实际Artifact、定位引用和逐项核验；用户修改与接受绑定版本。
- [ ] 不启用子Agent/DAG/Board/Join或本机读写也能独立验本轮文本能力，权限flags不因此开放。
- [ ] 本人接受、模型判断、工程回执各自记录；本机失败仍另列，文本通过不把整项目标accepted。

状态/版本/权限规则可用受控fixture验证；凡本轮声称真实模型、工具、文件、进程、联网或环境已经可用，必须保留实际回执。Mock、接口示例和HTML演示不能替代真实连通或阶段场景验收。

语义质量按原始需求、材料和证据审阅，不以字数/固定关键词替代；工具退出0也不自动证明整个用户任务完成。只加与本轮风险有关的检查，不追求测试数量。
