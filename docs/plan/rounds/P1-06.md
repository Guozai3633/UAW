## 3. 每项开发任务

1. 对文件工具及shell修改采集before/after，登记实际ChangeSet。
2. 登记有Hash/来源/版本的成果，实现首个格式的预览与下载。
3. 提供按文件审阅、接受/拒绝/反馈；接受意见与真正应用修改分开。
4. 实现整文件版本恢复及当前内容冲突检查，改动后使旧验证失效。

- [ ] 工具外命令造成的修改同样出现在Diff。

- [ ] 成果可打开，引用指向实际内容；无内容不能publish成功。

状态/版本/权限规则可用受控fixture验证；凡本轮声称真实模型、工具、文件、进程、联网或环境已经可用，必须保留实际回执。Mock、接口示例和HTML演示不能替代真实连通或阶段场景验收。

语义质量按原始需求、材料和证据审阅，不以字数/固定关键词替代；工具退出0也不自动证明整个用户任务完成。只加与本轮风险有关的检查，不追求测试数量。
