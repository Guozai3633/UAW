## 3. 每项开发任务

1. 实现候选/确认结果BoardEntry及依赖版本CAS，不共享可变提示词。
2. 子返回AgentResult，Join校验目标、实际证据、版本和未完成项。
3. 结果冲突/过期返回主Agent重新判断，失败可以部分交付但必须明示。
4. 父最终综合仍经过P1完成核验，子completed不等于整个Task成功。
