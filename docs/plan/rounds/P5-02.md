## 3. 每项开发任务

1. 先取得ExecutionLease/fencing，校验协议兼容及必要迁移。
2. 按当前主体/配置重建访问，Tool对账未决效果，Workspace检查实际文件/环境。
3. 只续跑满足前置条件节点；重复worker/过期租约不能再提交。
4. 区分事件replay、执行resume与新Run rerun，不能承诺联网/模型结果完全复现。

## 6. 验收条件与必要验证

- [ ] 网络超时后实际已成功的写不再次派发，无法查询时如实等待/受阻。
- [ ] 撤销权限、丢失设备、变更用户文件、旧模型下线阻止不安全续跑。
- [ ] 重复恢复请求只领取一次，事件续接不重复显示或追加结果。

状态/版本/权限规则可用受控fixture验证；凡本轮声称真实模型、工具、文件、进程、联网或环境已经可用，必须保留实际回执。Mock、接口示例和HTML演示不能替代真实连通或阶段场景验收。

语义质量按原始需求、材料和证据审阅，不以字数/固定关键词替代；工具退出0也不自动证明整个用户任务完成。只加与本轮风险有关的检查，不追求测试数量。
