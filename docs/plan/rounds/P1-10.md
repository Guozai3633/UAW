## 3. 每项开发任务

1. 按D04锁定React/TypeScript/Vite稳定组合，FastAPI接主体检查/请求去重/资源归属与最小HTTP接口。
2. 接提交、模型选择、发送后TaskFrame浅色提示、Item/SSE续接、审批和取消。
3. 接本机项目选择、实际命令状态、Diff与成果预览/下载，前端不解析模型文字猜状态。
4. 开发入口与真实账号试用认证分开；有趣状态文案只作为展示槽位，不影响状态语义。

## 6. 验收条件与必要验证

- [ ] 从页面发起实际任务，刷新/断连续接不重复提交或重复项。
- [ ] 能批准/取消、查看真实退出码及文件变化；理解提示不覆盖原文。
- [ ] 未实现能力不显示可用；未使用真实账号认证的入口不对公网开放。

状态/版本/权限规则可用受控fixture验证；凡本轮声称真实模型、工具、文件、进程、联网或环境已经可用，必须保留实际回执。Mock、接口示例和HTML演示不能替代真实连通或阶段场景验收。

语义质量按原始需求、材料和证据审阅，不以字数/固定关键词替代；工具退出0也不自动证明整个用户任务完成。只加与本轮风险有关的检查，不追求测试数量。
