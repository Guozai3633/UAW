## 3. 每项开发任务

1. 主循环提供会话候选摘要，由当前LLM根据任务决定是否agents.invoke。
2. 先运行一个有界子任务；Factory切分父预算、继承模型并求权限交集。
3. 隔离上下文和必要工作区，通过引用消息、wait和cancel收集结果。
4. 更新Run取消传播与子树状态，默认不启用任意递归或并行写。

## 6. 验收条件与必要验证

- [ ] 创建角色后不自动invoke，简单任务仍可单Agent完成。
- [ ] 子实例不能看到未授权父完整历史或取得比父更大的权限/预算。
