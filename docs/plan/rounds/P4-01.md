## 3. 每项开发任务

1. 实现显式/推断候选、scope/保留政策、冲突槽及受控提交。
2. 读与贡献开关分开，推断不自动变成用户事实。
3. 支持召回、明确限定删除、索引/摘要/缓存失效及物理清理回执。
4. 将记忆来源、有效期和撤销暴露给用户，不扩大跨会话读取权限。
