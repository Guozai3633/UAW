1. 按docs/api/CONVERSATION_REVISION.md更新公共维护源，发布精确DTO、动作分支、幂等/CAS和错误契约；没有新字段不能私加参数。

4. 固定API/页面消费示例、最小来源、实际版本和目录归属；随后才正式发布worker基线。

## 6. 验收条件与必要验证

- [ ] 动作/字段/返回/事件/状态机及迁移可审阅，现行旧客户端与旧记录有明确兼容或拒绝行为。
- [ ] 消息提交无Artifact硬依赖，缺真实授权的动作仍拒绝；取消/终态不会被续跑复活。
- [ ] 生成对象/接口一致，工人用准确发布版本消费；文档修订不能算新运行能力验收。

状态/版本/权限规则可用受控fixture验证；凡本轮声称真实模型、工具、文件、进程、联网或环境已经可用，必须保留实际回执。Mock、接口示例和HTML演示不能替代真实连通或阶段场景验收。

语义质量按原始需求、材料和证据审阅，不以字数/固定关键词替代；工具退出0也不自动证明整个用户任务完成。只加与本轮风险有关的检查，不追求测试数量。
