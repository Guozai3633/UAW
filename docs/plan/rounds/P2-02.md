## 3. 每项开发任务

1. 接一个已配置搜索提供方及web.read，普通用户不设置API key。
2. 校验DNS/重定向与获准网络范围，搜索摘要和实际读取分开。
3. 记录URL、抓取时间、实际内容版本与可定位引用，处理大结果分页。
4. 提供未配置、限流、无内容和失效链接的真实失败反馈。
