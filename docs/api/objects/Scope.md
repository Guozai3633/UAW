# Scope

状态：对象契约0.1；可用范围见具体接口与实施记录。所属：公共协议。

资源域选择器，不是授权凭证。

[对象总索引](../OBJECTS.md) · [接口总入口](../README.md)

## 字段

| 字段 | 类型 | 必填 | 含义 | 结构约束 |
| --- | --- | --- | --- | --- |
| `principal_id` | [ID](./ID.md) | 是 | 有效主体，由可信通道提供 | 类型约束见对应对象 |
| `conversation_id` | [ID](./ID.md) | 否 | 会话范围 | 类型约束见对应对象 |
| `task_id` | [ID](./ID.md) | 否 | 任务范围 | 类型约束见对应对象 |
| `project_id` | [ID](./ID.md) | 否 | 已绑定项目范围 | 类型约束见对应对象 |
| `resource_refs` | 数组&lt;[Ref](./Ref.md)&gt; | 否 | 进一步收窄资源 | 最少项 `0`；最多项 `128` |
| `capabilities` | 数组&lt;[NonEmptyText](./NonEmptyText.md)&gt; | 否 | 请求/有效能力标签，服务端求交集 | 最少项 `0`；最多项 `128` |

拒绝未声明字段。可选字段省略表示没有提供；只有显式 `null` 分支允许空值。默认注解不会自动写入请求。

## 运行时约束

- 客户端scope只能作为请求选择器，不能覆盖可信scope；单用户也验证对象归属。
