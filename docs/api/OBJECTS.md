# 对象总字典

[接口总入口](README.md)。所有对象来自同一份[JSON Schema](../../contracts/uaw.schema.json)，包括业务实体、请求DTO、分支对象和每个接口的严格返回结构。生成对象多不等于需要建立相同数量的数据库表或服务。
