## 改动与原因

原开发页面代理固定 8000/5173，不能独立启动体验环境。`serve_existing_web.py` 新增显式
host/port/backend-port，默认仍为原地址；精确 Host/Origin、只转发原 Cookie/CSRF、请求/回复大小限制保持。
只绑定已列明的回环地址，不接受公网地址或任意 hostname，不信任 forwarded headers。

不同端口共享同一主机的 Cookie，故 H01 选择 `127.0.0.2:8011/5181`，
Settings 只增加这个明确回环值，browser_origin 仍必须与 host 精确匹配。
实际 IPv6 测试连接曾被 Windows 拒绝，原失败保留；未修改防火墙或系统网络设置。

H01 用固定源码快照而非浮动 integration 启动；前端消费已接受的 MS-U3b 原构建并核对三文件摘要。
独立数据库、用户/管理员登录密钥、分页/浏览器密钥、blob、日志和端口。
从管理员当前配置读取一致的目录及版本记录，只复制平台配置，不复制聊天、Run、浏览器 session 或 native 授权。
模型凭据沿用已授权 OS 保管来源，不明文保存或输出；实际调用仍受固定模型/预算和原账本约束。
所有 feature flags 保持关闭；本次只准备文本流程，本机文件首次发布/恢复仍未通过。
